# Fornax

[English](README.md) | 日本語

8つのティアのかまどを追加します。ティアが上がるほど速く、一度に多く焼けます。

*Fornax* はラテン語で「かまど」です。

## 対応環境

| | |
|---|---|
| Minecraft | 1.21.1 |
| ローダー | NeoForge 21.1.248 |
| Java | 21 |

## ティア

| ティア | 素材 | 1回の時間（tick） | 1回に焼く数 | スロット | 1秒あたり |
|---|---|---|---|---|---|
| — | バニラのかまど | 200 | 1 | 1 | 0.1 |
| 1 | 銅 | 83 | 1 | 1 | 0.24 |
| 2 | 鉄 | 34 | 1 | 1 | 0.59 |
| 3 | 金 | 14 | 1 | 1 | 1.4 |
| 4 | ダイヤモンド | 6 | 4 | 1 | 13 |
| 5 | ネザライト | 2 | 16 | 1 | 160 |
| 6 | ネザースター | 1 | 64 | 1 | 1,280 |
| 7 | 圧縮ネザースター | 1 | 128 | 4 | 10,240 |
| 8 | 超圧縮ネザースター | 1 | 256 | 16 | 81,920 |

1回の時間は、バニラのかまどで 200 tick かかるレシピの場合です。ほかのレシピは同じ割合で長く・短くなります。

## 燃料

1個あたりの燃料はバニラのかまどと同じです。どのティアでも石炭1個で8個焼けます。
バニラのかまどと同じく、一度燃え始めた燃料は、焼く物が無くても燃え続けます。

## 電気かまど

燃料の代わりに Forge Energy（FE）で動くかまどです。ティアは燃料のかまどと同じで、それに加えてバニラのかまどと同じ速さの「電気かまど」があります。

- 1個あたり、レシピの1 tick につき 20 FE 使います。200 tick のレシピなら 4,000 FE です。
- 電力はどの面からでも入ります。
- 横の面は電力だけを受け取ります。焼く物は、燃料のかまどと同じく上の面から入れます。

| かまど | 蓄電量 (FE) |
|---|---:|
| 電気かまど | 8,000 |
| Tier 1 | 9,600 |
| Tier 8 | 2,147,483,647 |

## スロット

1つのスロットには「1回に焼く数の2倍」か「1スタック」の多い方まで入ります。

## ホッパー・パイプ

| 面 | |
|---|---|
| 上 | 焼く物。一番空いているスロットに入ります |
| 横 | 燃料 |
| 下 | 焼けた物と、溶岩を使ったあとの空のバケツ |

## レシピ

電気かまど：

```
C C C
C F C
C R C
```

C：丸石　F：かまど　R：レッドストーンブロック

Tier 1〜6（燃料・電気とも）：

```
M M M
M F M
M C M
```

M：そのティアの素材　F：同じ種類で1つ下のティアのかまど（Tier 1 はバニラのかまど、または電気かまど）　C：燃料のかまどは石炭ブロック、電気かまどはレッドストーンブロック

| ティア | 素材 |
|---|---|
| 1 | 銅インゴット |
| 2 | 鉄インゴット |
| 3 | 金インゴット |
| 4 | ダイヤモンド |
| 5 | ネザライトインゴット |
| 6 | ネザースター |

Tier 7・8（燃料・電気とも）：

| ティア | レシピ |
|---|---|
| 7 | Tier 6 を8個、真ん中にガストの涙 |
| 8 | Tier 7 を8個、真ん中に不死のトーテム |

## 設定

`config/fornax-server.toml` でティアごとに `ticks`（1回の時間）と `batch`（1回に焼く数）を変えられます。
`capacityBatches` は1つのスロットに何回分入るかです。
`electric.energyPerTick` はレシピ1 tick あたりの FE、`electric.bufferTicks` は電気かまどが蓄えた分で動き続けられる長さです。

`config/fornax-client.toml` の `hideRecipeBook` でレシピ本ボタンを隠せます。

## ビルド

```
run.bat                   # コンパイルして開発用クライアントを起動（ダブルクリック可）
gradlew build             # jar を作る
gradlew runGameTestServer # ゲームテストを全部実行して終了
gradlew runData           # モデル・テクスチャ・レシピ・言語ファイルを生成し直す
```

`JAVA_HOME` が JDK 21 を指しているか、`java` に PATH が通っている必要があります。
